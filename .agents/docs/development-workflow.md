# Development Workflow

## Standard Feature

Understand
→ Explore
→ Plan
→ Approval
→ Implement
→ Test
→ Review
→ Fix
→ Document
→ Commit

---

## Small Change

For small changes:

Understand
→ Implement
→ Test
→ Review

---

## Large Feature

For large features:

Brainstorm
→ Architecture
→ Database Design
→ Plan
→ Approval
→ Backend
→ Testing
→ Frontend
→ Integration
→ Review
→ Documentation
